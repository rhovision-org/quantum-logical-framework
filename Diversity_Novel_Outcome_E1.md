# Diversity E1: does complementary composition create a closure type self-composition cannot? (#290)

Part of the [Quantum Logical Framework (QLF)](README.md). **ZFA** (Zero Free Action) is equal and
opposite quantum logical action with zero free energy, the principle of QLF. Issue #290 asks whether
emergence favors diversity. Its gate table puts **D8b / Theorem E1** (a complementary composition
generates a closure type that no homogeneous composition reaches) before any advantage measure, and
names the Lean milestone `complementary_composition_creates_novel_closure`. The relation families
tried so far ([Diversity_Revision_D8c2b.md](Diversity_Revision_D8c2b.md), PR #299's D3T) stopped at
D8c2, an advantage count. This note runs E1 itself, on the smallest relation the primitive algebra
gives, with no advantage measure.

## §1 Pre-registration (committed before the companion script was run)

### Objects

* A history is **open** if it is not count-balanced, **closed** if it is.
* The **type** of a closed history is its Pauli fold, `+I` or `−I` (`count_balanced_pauli_closed`
  and `fold_eq_connectionPhase`). This is the equivalence `~` of D2, and it is not chosen for the
  result: for a single body it is exactly the observational class, what closure tests with phase can
  distinguish ([`lean/QLF_ObservationalEquivalence.lean`](lean/QLF_ObservationalEquivalence.lean)).
  Two words with the same fold are one type, so syntax does not inflate the count.
* **Composition** is concatenation, the only primitive join. `R(a, b, c)` holds when `a ++ b` is
  closed with type `c`.
* **Homogeneous** generators are pairs `(a, a)`. **Complementary** generators are pairs of open
  histories whose net action vectors cancel.
* `N_hom = |{c : ∃ a, R(a, a, c)}|` and `N_mixed = |{c : ∃ a ≠ b, R(a, b, c)}|`.

No distance, matching rule or target geometry enters.

### Tests

| | Claim under test | Passes if | Prior |
|---|---|---|---|
| N1 | an open history never closes with itself | no open `a` with `|a| ≤ 4` has `a ++ a` closed | pass: the net vector doubles |
| N2 | a closed history composed with itself is always `+I` | every closed `a` with `|a| ≤ 6` has `fold(a ++ a) = +I` | pass: the fold of `a` is `±I` and squares to `I` |
| N3 | complementary open pairs reach `−I` | some open `a ≠ b` has `a ++ b` closed of type `−I`; witness `a = ^<`, `b = v>` | pass, via `interleaved_xlvr_folds_to_negI` |
| N4 | `−I` from complementary pairs needs no `−I` constituent | N3's witness has open constituents, so neither carries a type at all | pass by construction; recorded as the control against "repetition of an existing type" |
| N5 | census (report only) | over ordered open pairs with `|a|, |b| ≤ 3` and `a ++ b` closed, the counts of each type | none stated |

**Verdict rule.** If N1 to N3 pass, then `N_hom = 1` (`{+I}`) and `N_mixed = 2` (`{+I, −I}`) on
this relation, so E1 holds here and D8b passes in this class: the `−I` closure type is generated by
complementary composition and by no homogeneous one. If N2 fails, E1 fails here. The result says
nothing about D8c (an advantage under a measure), D9 (persistence) or D10 (physical relevance), and
nothing about relations other than concatenation.

**Recorded beforehand.** The result is small and the note says so. Its use is to separate E1 from
the advantage question that stopped D8c2: the novel outcome exists at the first step, so the open
part of #290 is whether it confers an advantage and persists, not whether complementary composition
reaches anything new. It is consistent with D3T.6's failure in PR #299: the phase of a join is not
fixed by either side's boundary record, because it is created by the join.

## §2 Results

Run by [`diversity_novel_outcome.py`](diversity_novel_outcome.py); output in
[`data/diversity_novel_outcome.json`](data/diversity_novel_outcome.json). Proved in
[`lean/QLF_DiversityNovelOutcome.lean`](lean/QLF_DiversityNovelOutcome.lean), no axioms.

| | Result | Verdict |
|---|---|---|
| N1 | 0 open histories of length `≤ 4` close with themselves | **pass** (`self_compose_balanced_iff`, all lengths) |
| N2 | all 5,297 closed histories of length `≤ 6` (the empty one included) give `a ++ a` of type `+I` | **pass** (`self_composition_type_one`, all lengths) |
| N3 | `^<` and `v>` are open and `^<v>` is closed of type `−I` | **pass** (`complementary_composition_creates_novel_closure`) |
| N4 | the witness's constituents are open, so the `−I` is not a repeated constituent type | **pass** |
| N5 | 5,568 ordered closing open pairs with `|a|, |b| ≤ 3`: 3,712 of type `−I`, 1,856 of type `+I` | report |

**Verdict.** `N_hom = {+I}` and `N_mixed = {+I, −I}`. E1 holds on the concatenation relation, and
D8b passes in this class: the `−I` closure type is generated by complementary composition and by no
self-composition, at any length.

Two further facts the run shows. The smallest witness is shorter than the pre-registered one: `^` and
`v` already close to `−I` (`minimal_complementary_pair`), since every conjugate pair folds to `−I`.
And among closing open pairs `−I` is the majority type, two to one in N5. So the novel type is not
rare. Whether it confers a continuation advantage under a declared measure (D8c), and whether it
persists under iterated composition (D9), are the open parts of #290.
